# 맛따라 멋따라 — 작업 요약 보고 (2026-09-16 기준)

해커톤 마감은 2026년 9월 말이고, 심사 기준은 "사내 업무 자동화" 단 하나다. 지금까지 프로젝트는 기획안 확정부터 데스크톱 웹 포털 완성, 리뷰 시스템 전면 개편, 그리고 오늘 있었던 실배포 대응까지 총 26차례의 작업 단위(1~18차, 18차는 3단계로 세분)를 거쳤다.

## 지금까지 완료된 것

**기반 구축 (9월 4일~7일, 1~9차)**: Neon Postgres 스키마와 실제 카카오 로컬 API로 수집한 회사 주변(퇴계로 173 기준 반경 600m~1km) 실존 장소 90여 곳 데이터를 확보했고, 둘러보기 피드·리뷰 작성·장소 상세·관리자 페이지까지 핵심 화면 4종을 모두 구현했다. 이 시기에 사용자 본인 컴퓨터에서 로컬 실행까지 직접 확인했고, 을지로 힙지로 권역 실존 핫플 19곳을 별도로 조사해 등록했다.

**디자인 및 UX 반복 (9월 7일~8일, 6~10차)**: 모바일 앱이 아니라 회사 PC 모니터로 쓰는 데스크톱 웹 포털이라는 방향이 명확해지면서 1200~1440px 레이아웃으로 전면 개편했고, "홍대/을지로 그래피티" 무드를 시도했다가 가독성 문제로 "캐치테이블/토스풍 모던 미니멀" 톤으로 재교체했다. 이 시기에 사내 경쟁 앱과 차별화되는 핵심 킬러 기능인 [조건 추천](90분 점심+카페 페어링 자동 추천)도 처음 만들어졌다.

**운영 안정화 (9월 11일~15일, 11~15차)**: 실배포 사이트를 직접 점검해 보안 조치(ADMIN_PASSWORD 설정)를 완료했고, 로그인 게이트 관련 설계 의도를 문서로 명확히 정리했다. 임직원 실사용 패턴에 맞춰 상황 필터를 재정비하는 과정에서 "저녁/회식"과 "힙지로·트렌드" 필터가 똑같아 보이던 문제도 잡았다.

**핵심 전환 (9월 16일, 16~17차)**: "KPR의 점심시간은 90분이다"라는 브랜드 컨셉을 카피와 시간예산 기본값에 반영했고, 이어서 이번 프로젝트에서 가장 큰 구조 변경인 **리뷰 시스템 패러다임 전환**을 진행했다. 기존의 무거운 "게시판형 긴 리뷰 작성" 방식 대신, 카드에서 한 번 터치로 남기는 "🔥 또 갈래요/🤔 굳이" 반응과 15초짜리 짧은 꿀팁 제보로 참여 장벽을 크게 낮췄다.

## 오늘(9/16) 진행한 것 — 18차 시리즈

1. **18차 (UI 개편)**: 사이드바 상황 필터를 5개에서 3개로 줄이고, 거리 필터를 3단계에서 2단계로 단순화했다. 식당 카드 하단에 근처 카페를 추천하는 "☕️ 추천 코스" 태그를 새로 붙였고, 그동안 눈에 안 띄던 [조건 추천] 기능을 GNB 배지와 사이드바 대형 배너로 전면에 끌어올렸다.
2. **18차-1 (배포 에러 긴급 수정)**: 16~18차를 처음으로 한 번에 push한 직후 Vercel 빌드가 실패했다. 원인은 리포에 이미 있던 파일(`use-feed-filters.ts`, 9월 8일에 추가된 "가볍게/든든하게" 서브 필터 기능)과 이번 작업분 사이의 참조 불일치였다. Vercel 로그와 GitHub의 마지막 정상 배포본을 직접 열람해 원인을 확인하고 수정했다.
3. **18차-2 (실사용 피드백 3건)**: 재배포 확인 후 실제로 써보고 준 피드백 3가지를 반영했다 — 장소 상세 페이지의 "접대 꿀팁 체크리스트" 섹션 삭제, "가볍게/든든하게" 서브 필터 재삭제, 그리고 "힙플레이스·디저트" 필터에서 카페가 6곳만 보이던 것을 확인해보니 관리자가 수동으로 켠 것만 보여주는 설계였음을 밝히고 전체 카페가 다 보이도록 변경했다.

이와 별도로 Neon SQL Editor 마이그레이션(`is_staff_pick` 컬럼, 리뷰 content 필수 해제, `place_stats` 뷰 갱신)도 오늘 성공적으로 실행 완료를 확인했다.

## 지금 상태

코드는 18차-2까지 사용자 컴퓨터의 matdda-app 폴더에 전부 반영되어 있다. Neon 마이그레이션은 완료됐지만, **18차-2에서 고친 파일 4개(feed-browser.tsx, feed-queries.ts, page.tsx, places/[id]/page.tsx)는 아직 커밋+push 전**이라 실제 배포 사이트에는 반영되지 않은 상태다.

## 우선순위 개선사항

1. **[최우선] 18차-2 수정본 커밋+push, Vercel 재배포 확인.** 지금 당장 해야 할 유일한 일. 전에 안내한 방식대로 VS Code 소스 제어에서 스테이징 → 커밋 → push 하면 된다.
2. **[최우선] 실제 참여 데이터 채우기.** 원터치 반응/15초 꿀팁으로 참여 장벽이 크게 낮아졌으니, 접대·외근·든든한 점심·힙지로 각 상황별 대표 장소 10~15곳에 직접 반응과 꿀팁을 남겨서 "0건" 화면을 없애는 작업이 필요하다. 확인 전 장소는 관리자 페이지의 "총무팀 픽" 토글로 신뢰 신호를 먼저 줄 수 있다.
3. 리뷰를 채우면서 관리자 페이지에서 사진도 함께 업로드하면 카드 완성도가 크게 올라간다.
4. 참여가 조금 쌓이면 [조건 추천]의 "오늘 여기로 결정!" 버튼을 직접 눌러 추천 채택률 로그(`recommendation_logs`)가 쌓이기 시작하게 하는 것도 좋다.

마감이 약 2주 남은 시점이라, 아래 두 가지는 지금은 보류하고 위 1~4번에 집중하는 것을 권한다.

- "90분 컨셉" 중간/전면 버전 확장 (90분 타임라인 상세 서술, 1+1 페어링 레이아웃 전면 개편)
- 관리자 페이지 모던 미니멀 톤 확장 (심사 기준과 직접 관련 없음)
